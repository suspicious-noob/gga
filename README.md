# GGA [GOG-Games Archive]

> A community preservation project for the historical download index from **gog-games.to**.
> 
🌐 Live Archive

Browse the archive directly in your browser:

https://suspicious-noob.github.io/gga/

No download or installation required.

## Overview

With the imminent shutdown of **gog-games.to**, a large amount of information risks disappearing permanently. While the website itself may eventually become inaccessible, many of its download mirrors and external links may continue to exist.

This repository serves as a simple archival snapshot of the site's game index.

The project intentionally consists of a single `index.html` file that can be opened locally in any modern web browser. No installation, build process, dependencies, or web server is required.

## Purpose

The archive aims to preserve:

- Game titles
- External download links
- Basic searchable index
- Historical reference of the site's catalog

It is **not** intended to replace the original website, nor does it host any game files.

## Features

- 📄 Single-file archive (`index.html`)
- 🔍 Instant browser search
- 💾 Fully offline
- ⚡ No JavaScript frameworks
- 🖥️ Runs in any modern browser
- 📦 No dependencies

## Usage

Simply download or clone the repository and open:

```text
index.html
```

That's it.

Everything runs locally.

## Why?

The internet loses useful resources every day.

When websites disappear, years of organization, metadata, and historical information often disappear with them. This project exists to preserve one small piece of gaming history before it is lost.

## Disclaimer

This repository **does not contain**:

- Game files
- Installers
- Torrents
- Cracks
- Copyrighted game content

It only preserves an index of publicly available links that were previously listed on the original website.

If any external links are no longer available, they have been preserved solely as historical references.
